## Task 12: Manual Testing Checklist

### Step 1: Test v2.0 to v3.0 Migration

**Objective:** Verify automatic migration of old v2.0 data to v3.0 format

**Steps:**
1. If you have existing v2.0 data in AsyncStorage, launch the app
2. Check console for "Migrated v2.0 data to v3.0" message
3. Verify all old shows appear in the app
4. Check AsyncStorage contains `mediaItems` instead of `shows`
5. Verify all migrated shows have `mediaType: 'show'`

**Expected Results:**
- Migration happens automatically on first launch
- No data loss
- All shows display correctly
- Console log confirms migration

## Known Limitations (Expected Behavior)

1. **Migration is one-way:** v2.0 data migrates to v3.0, but v3.0 backups cannot be used in v2.0
2. **Season/Episode data loss:** Converting a show to movie removes season/episode data
3. **Filter persistence:** Filters persist indefinitely until manually changed
4. **No undo:** Deletions and restorations are permanent
